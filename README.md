# Cafeteria Serenatto

A responsive website for **Cafeteria Serenatto**, showcasing a modern and stylish design using **Bootstrap 5**. The site is designed to provide an excellent user experience across all devices, including desktops, tablets, and mobile phones.

## Live Demo

Check out the live version of the **Cafeteria Serenatto** website [here](https://serenatto-powit63i8-guilherme-esperancas-projects.vercel.app/).

## Features

- **Responsive Design**: The website adapts seamlessly to different screen sizes, providing a consistent and optimized experience on all devices.
- **Bootstrap 5**: Utilizes the latest version of Bootstrap for a flexible, grid-based layout and modern UI components.
- **Interactive Menu**: Displays the café's offerings in an appealing and easy-to-navigate format.
- **Gallery Section**: Highlights images of the café’s ambiance, food, and drinks.
- **Clean and Modern UI**: A user-friendly and visually appealing interface designed for a relaxing browsing experience.

## Technologies Used

- **HTML5**: For structuring the web pages.
- **CSS3**: For custom styles and visual enhancements.
- **Bootstrap 5**: For responsive design, layout, and components.
- **JavaScript**: For adding interactive elements (optional).
